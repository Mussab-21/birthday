## 🚀 How to Deploy to Netlify Drop (2 Minutes)

The production build has already been generated in:
```
D:\Birthday\birthday-walk\dist\
```

1. Open your browser and go to: **[https://app.netlify.com/drop](https://app.netlify.com/drop)**
2. Sign in to your Netlify account (or continue with GitHub / Email).
3. Drag and drop the **`dist`** folder (`D:\Birthday\birthday-walk\dist`) directly into the upload area on Netlify.
4. Netlify will publish your site in seconds and give you a live URL (e.g., `https://romantic-walk-xyz.netlify.app`).
5. (Optional) In Netlify site settings:
   - Click **"Site configuration"** → **"Change site name"**
   - Pick a custom name like `a-night-walk-with-you` or `for-ninu`.

## 🐙 How to Push to GitHub / Git

The Git repository is already initialized and committed locally. To push to GitHub:

1. Create a new repository on [GitHub](https://github.com/new) (e.g. named `birthday-walk` or `for-aleena`). Make it **Private** if you want to keep the surprise confidential until her birthday.
2. Run these commands in PowerShell from `D:\Birthday`:

```powershell
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```
